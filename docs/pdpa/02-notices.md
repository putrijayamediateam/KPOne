## Putting it into KPOne (after approval)

1. **Patient QR notice.** The QR form currently shows a draft: "Notis privasi, draf UAT" (`resources/js/pages/PublicCheckIn/Show.vue`).
   Replace the text with the approved Bahasa Melayu text, and change `privacy_notice_version` in
   `config/public-intake.php` (currently `uat-draft-set04b-email-address-v2`) to a new approved version string.
   Sessions already started keep their own version.
2. **Job applications.** Set `HR_APPLICATIONS_PRIVACY_NOTICE_VERSION` in the server environment (not in code) and
   only then set `HR_APPLICATIONS_ENABLED=true`.
3. **Counter notice.** Print the approved patient notice as a poster at each counter and give it on request.
4. **Staff notice.** Give it with the employment contract; record that it was given.
5. Each change goes through a normal reviewed change in KPOne. Ask for it as a small, separate change.
