# Batch & expiry composition — 26 November 2026

The existing Batch & Expiry view now uses expandable batch/location balances instead of a nine-column horizontal table. Quantity and unit, location, expiry date/status and independent batch/hold status remain visible. Details retain SKU, original item, mapped medicine and received date, including the existing dash for missing dates. Each row explicitly represents one batch at one location. No nearest-expiry or available-stock calculation is introduced.

The existing directory projection, search/status/location/batch filters, pagination, permissions and actions are unchanged. Index script excluding imports is byte-identical to the Stock dependency. The new view has no stock mutation or report action. It preserves expired-plus-held rows, held-without-reason fallback and exact fractional/zero values. Expansion resets when the server projection changes; loading hides stale rows. Focus remains on a surviving row or falls back to the labelled list, without stealing focus subsequently moved elsewhere.
