# Panduan ringkas hari rintis

Panduan ini menerangkan langkah yang disokong oleh skrin KPOne semasa. Nama halaman dan butang dikekalkan dalam bahasa Inggeris supaya mudah dicari. Gunakan akaun sendiri dan pastikan cawangan yang dipilih betul.

1. [Pembantu Klinik](./ca.md)
2. [Doktor Residen](./doktor.md)
3. [Penyelia CA](./penyelia-ca.md)
4. [Apabila ada masalah](./bila-ada-masalah.md)

Ikut hanya tindakan yang dipaparkan untuk akaun anda. Jika butang tiada atau tindakan ditolak, jangan gunakan akaun orang lain atau cuba jalan lain. Rujuk panduan masalah dan pengendali klinik.

Gunakan rekod rekaan sahaja semasa latihan. Panduan ini tidak meluluskan penggunaan produksi. Semak perkara bertanda `[PERLU DISAHKAN]` dengan klinik sebelum hari rintis.
