# WA-01 — plain WhatsApp click-to-chat link

Status: local candidate. Owner-authorised 2026-10-22. Base: canonical main `5bf8612621373aa13f6f5b20b5605d9d6df87eb9` (DOC-05, PR #153). Branch: `feature/wa-01-whatsapp-link`.

## Change and boundary

A shared browser-only normaliser and link component add a plain `https://wa.me/<digits>` anchor beside phones already shown in full. There is no prefilled text, query string, click handler, audit/counter, fetch, server route, backend prop, permission, migration or dependency. Existing backend permissions still decide whether the phone reaches a page. Existing page-read audit behaviour is unchanged. No WhatsApp destination was opened during validation.

The anchor uses `target="_blank"`, `rel="noopener noreferrer"`, and `referrerpolicy="no-referrer"`. It reuses the existing outline Button, MessageCircle icon and Tooltip components, with the requested BM accessible name and number-disclosure tooltip. A 48px minimum target exceeds 44px even with fractional rounding at the validation browser's 80% zoom (measured 47.998 CSS px). Links are keyboard focusable. No state is persisted by this feature.

## Number rules

`resources/js/lib/whatsapp-link.ts` is the only normaliser. It strips spaces (including Unicode space separators), hyphens, single dots and parentheses, and accepts only ASCII digits plus an optional initial `+`. Controls, letters, mask characters, ellipses, repeated dots, URLs, query strings and multiple numbers separated by punctuation or additional plus signs are refused. Empty, non-string and overlong inputs are refused.

- The owner's explicit Malaysian mobile budget is **9–10 digits including local 01**. Local `01…` becomes `601…`; equivalent `601…` / `+601…` forms are accepted with the same budget.
- Malaysian landlines, including `+60` landlines, are refused.
- Other international numbers require a leading `+`, a nonzero first digit and 8–15 digits. No country is guessed for an unprefixed foreign number.
- Output is digits only. A rejected number produces no element, not a disabled or malformed link.

This is deterministic syntax handling, not a check that a number has a WhatsApp account. The explicit owner budget is retained; longer Malaysian mobile formats are not silently broadened.
