The Prepare tab lacked the demo's Doctor filter. This adds All, OTC counter and doctors derived only from existing authorized preparation cases, with bounded25-option paging and literal name search. The picker preserves the validated selection across searches/pages, keeps keyboard focus during paging, clears choices on failed reads and rejects stale branch responses. Ordinary list polling cannot replace a pending picker search. Authenticated encrypted selectors avoid adding public-ID schema or exposing internal IDs; existing branch/case permissions and sensitive no-store responses remain enforced. No clinical writes, grants, migrations or Ready lifecycle are added.
