# Drug label pilot checks (DSP-9)

Two checks stand between the KPOne drug label and the pilot. They are done by people, not code:

1. **[Printer test](printer-test.md)** — print the worst-case labels on the real printer and sticker stock at the
   pilot branch and record what you see. A CA Supervisor prints; the owner or an Administrator sets Business
   details and the logo first.
2. **[Pharmacist review](pharmacist-review.md)** — a pharmacist reads the label wording and the length limits
   and signs off, or says what must change. Give the pharmacist this folder or a printout of that page.

Do the printer test first: a different sticker size changes every limit the pharmacist is asked to accept.

**What this pack is not.** It is not a regulatory opinion and it does not approve the label. Nothing in KPOne
changes until the owner decides on the answers, and any change is a separate piece of work.

All names, numbers and addresses in this pack are made up. The sample labels were produced by KPOne's own
label layout code (`DrugLabelLayout`) on 2026-11-05, so their line breaks and limits match a real print with the
same header. The clinic's real name, address and contact can add or remove a line or two.
